⚙️ React SPA Architecture
S
Routing: BrowserRouter → /review/:token/* → ProtectedRoutes (validates token against REACT_APP_VALID_TOKENS env var) → Layout (sticky nav) → page routes
S
Data fetching: All pages use direct fetch() in useEffect — NOT useApi() hook (stale reference bug in React 19 production). API params: document endpoint uses name=, comments uses document=.
S
API proxy: Netlify Function api-proxy.mjs (ES module) proxies all /api/v1/* requests to api.magruder.co. Handles CORS.
S
Document viewer: ReactMarkdown with custom components. Review mode: click paragraph to comment. Comment panel with per-reviewer color coding (Michael = #F86822, Doug = #1E3455).
S
Series: MASTER, PIA, SOURCE, CC_Reference, CC_Integration, E-Series (search filters + Explore sidebar categories)
⚙️ VPS / Corpus Architecture
V
Container: cc_mcp_server_cc-mcp_1 — FastMCP server. Module-level DB init (not per-session lifespan — LL-076).
V
Corpus DB: SQLite at /app/cc_metadata.db. Tables: documents (file_name, series, doc_class, title, word_count, file_size), corpus_fts (full-text search).
V
Ingest pattern: SCP file to VPS → docker cp to container → INSERT/UPDATE documents table + INSERT OR REPLACE corpus_fts. Script template: ingest_eguide.py in outputs dir.
V
Pre-flight: ssh root@204.168.190.66 'bash /usr/local/bin/cc_preflight.sh' via osascript. Checks Docker status, crash loops, OAuth endpoint, MCP auth gate, CC_STATE.md freshness.
V
Dispatch Hub: FastAPI at port 8100. Routes via nginx at /bridge/*. Job log at /opt/dispatch-hub/logs/dispatch_hub.log. GET /log endpoint exposes structured log entries.
V
Portal Sweep System: Three daily functional sweep scripts at /opt/sweeps/: admin_sweep.py (23 checks — links, APIs, services), review_sweep.py (12 checks — routes, OAuth, Identity), reader_sweep.py (7 checks — portal, API proxy). VPS cron daily 7am UTC. JSON reports at /opt/sweeps/logs/, 30-day retention. Weekly Cowork content sweep: Mondays 8am CT (portal-content-sweep scheduled task).

🔧 Known Issues & Fixes
FIXED
useApi() stale reference: Hook creates new fn refs each render; useEffect([]) captures stale first-render ref → silent failures in production (React 19). Fix: replace all useApi() calls with direct fetch() in useEffect. Affects: Explore.js, DocumentViewer.js, Search.js.
FIXED
Wrong API params: document endpoint needs name= (not file=), comments endpoint needs document= (not file=). Caused "Error: Failed to fetch" on document open.
FIXED
Build EPERM: build/_redirects gets locked from prior sessions. Fix: always use BUILD_PATH=/tmp/mac-cc-build to build to /tmp.
FIXED
JS apostrophe syntax error in gate: Apostrophes (you're, It's) inside single-quoted innerHTML JS strings crash page with parse error → white screen. Fix: replace with unicode escapes ’. Applied Apr 21.
FIXED
File digest deploy wipes unlisted files: ops-environment.html, ops-threads.html, CC_Ecosystem_Map.html disappeared after gate deploy. Fix: always include ALL files in every deploy manifest.
FIXED
reader.magruder.co routing (Netlify conditions): conditions = {Host = [...]} in netlify.toml doesn't support Host matching. Sequential Reader loaded index.html instead of reader.html. Fix: edge function (reader-router.mjs) inspects Host header directly. Applied Apr 30.
NOTE
Netlify Identity API invite unreliable: POST to /users/invite returns HTTP 204 but user doesn't always appear in user list. Always use the Netlify dashboard UI to invite and verify registration.
NOTE
CLI deploy + netlify.toml conflict: Running npx netlify deploy from the outputs directory triggers a rebuild instead of deploying pre-built files. Always deploy from /tmp/mac-cc-build.
NOTE
Sandbox SSH limitation: Cowork bash sandbox cannot reach ~/.ssh/cc_mcp_key. All SSH/SCP to VPS must go through osascript (Control_your_Mac). Never use Bash tool for remote VPS operations.
NOTE
Apostrophe path rule in osascript: The workspace folder '_Claude_CC2026 contains a literal single-quote. Cannot be escaped inline in AppleScript do shell script strings. Only working pattern: write a .sh script via Write tool, execute via do shell script "bash " & quote & "/path/to/script.sh" & quote.
